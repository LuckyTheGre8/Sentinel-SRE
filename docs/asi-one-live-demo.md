## Judge questions

- **Did you repair this service?** No; these are public testing endpoints. This run demonstrates live detection, evidence collection and a separate healthy control.
- **Did all five agents execute?** Only claim the workers whose results appear in the trace. Remediation is not executed in this read-only run.
- **Why a historical timestamp?** To demonstrate actual available commit history within the seven-day analysis limit. The current 503 is intentionally generated by the test endpoint.
- **Where is ASI:One used?** It is the chat interface, and the live orchestrator can call the configured ASI:One adapter for evidence synthesis. JSON actions are parsed directly. Confirm actual synthesis success in the returned warnings/logs before claiming it.
- **What would a full remediation demo require?** A repository and deployed service under your control, scoped GitHub credentials, a reviewed proposal and approval, then an independently observed recovery after deployment.
